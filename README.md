## 🚀 Getting Started

### Prerequisites
* Node.js (v18+)
* npm (v9+)

### Installation & Local Run
```bash
# Clone the repository
git clone https://github.com/Kams63/executive-portfolio.git

# Navigate into the project
cd executive-portfolio

# Install dependencies
npm install

# Start the local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
